One original fortune-cookie line for a software engineer, 67 characters:

> A green build on Friday means Monday will explain why it was lying.

The line is written for a tired engineer who knows the Friday green build is a trap: every check passes, then Monday arrives and the build's lie unravels. The funniest word — "lying" — sits at the very end.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` (Node 22, stdlib only) validates the line is one line of 1–120 characters, then writes it to `/output/entry.txt` with no trailing newline. Deterministic: identical bytes on every run, from any working directory.
